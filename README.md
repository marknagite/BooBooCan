# BooBooCan

Учебный проект на **Qt 6 + C++17 + Qt Widgets + PostgreSQL**.  
Приложение для заказа напитков с готовыми позициями и конструктором собственного напитка.

## Что уже реализовано

- Подключение к PostgreSQL через `QPSQL`
- Экран готовых напитков (карточки, фото, выбор размера и температуры)
- Создание заказа готового напитка в БД
- Конструктор напитка с предпросмотром и подсчётом цены
- Создание кастомного заказа в БД
- Экран статуса заказа с автообновлением
- История заказов в статусе заказа
- Экран настроек (тема, валюта, город, имя, фото) через `QSettings`

## Технологии

- Qt 6 (Widgets, Sql)
- C++17
- PostgreSQL
- CMake
- Без QML
- Без `.ui`

## Структура проекта

- `main.cpp` — вход в приложение
- `mainwindow.*` — навигация и экраны
- `databasemanager.*` — работа с БД
- `readydrinkswidget.*` — готовые напитки
- `customdrinkwidget.*` — конструктор напитка
- `orderstatuswidget.*` — статус и история заказов
- `settingswidget.*` — настройки приложения
- `drink.h`, `order.h` — модели
- `assets/` — изображения и графика

## Требования

- Qt 6.10.x (MinGW 64-bit)
- PostgreSQL (локально или доступ по сети)
- Драйвер `QPSQL`

## Настройка базы данных

В проекте используется база `BooBooCan` и таблицы:

- `public.ready_drinks`
- `public.orders`

Если нужно, добавь поле времени приготовления:

```sql
ALTER TABLE public.orders
ADD COLUMN IF NOT EXISTS estimated_minutes INT DEFAULT 2;
```

## Запуск в Qt Creator (рекомендуется)

1. Открыть `CMakeLists.txt` в Qt Creator.
2. Выбрать Kit: **Qt 6.10.x MinGW 64-bit**.
3. Собрать и запустить проект.

## Альтернатива через qmake

В репозитории есть `BooBooCan.pro` для совместимости.  
Можно открыть `.pro`-файл в Qt Creator, если нужен qmake-поток.

## Runtime-сборка для запуска без Qt

Для запуска на ПК без установленного Qt используется отдельно собранный runtime-пакет (exe + dll + assets).
